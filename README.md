# Scaling Optimization-Oriented Hypernetworks for Implicit Neural Representations

Code for **Scaling Optimization-Oriented Hypernetworks for Implicit Neural Representations** (NeurIPS 2026).

> **Initial partial release.** This repository currently contains selected, standalone hypernetwork components and a synthetic CPU example. The complete training and evaluation pipelines, dataset integrations, and pretrained checkpoints are being prepared. This version does not reproduce the paper's benchmark results.

## Overview

The project studies optimization-oriented hypernetworks for generating implicit neural representations (INRs). The architecture uses weight tokens and attention-based, chain-rule-inspired forward and backward message passing to predict parameter updates.

The current release focuses on the reusable components underlying that computation. It accepts task embeddings directly; signal encoders and the complete iterative `Hypernet` controller are not included yet.

## Included in this release

| File | Contents |
| --- | --- |
| [`hypernet_core.py`](hypernet_core.py) | Target-network interface, residual MLP, row-wise weight encoder/decoder, task-conditioned token initialization, optimization blocks, and token normalization |
| [`model/encoder/transformer.py`](model/encoder/transformer.py) | Self-attention and cross-attention wrappers |
| [`examples/minimal_components.py`](examples/minimal_components.py) | One component-level update on a small coordinate MLP using synthetic task embeddings |
| [`tests/test_components.py`](tests/test_components.py) | Shape, gradient, batch consistency, and state-dictionary checks |
| [`requirements.txt`](requirements.txt) | Minimal pinned dependencies for this release |

The main components are:

- `ModuleEncoder` / `ModuleDecoder`: map each output-neuron weight row to a token and back to a weight matrix. The learned codec is not an exact inverse.
- `InitWeightHypernet`: initialize weight tokens from task embeddings using learned queries.
- `OptBlock` / `OptLayer`: perform learned forward and backward message passing and predict updates.
- `FIN_FOUT` / `ParamLN`: provide endpoint processing and update normalization.
- `TargetNet` / `MLP`: supply the target-network interface and shared MLP building block.

## Quick start

Run the following commands from the repository root. The minimal example needs no dataset, checkpoint, CUDA extension, or GPU.

```bash
uv venv --python 3.12
source .venv/bin/activate
uv pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cpu
uv pip install einops==0.8.1

python -m examples.minimal_components
python -m unittest discover -s tests -v
```

Alternatively, install the dependencies with `python -m pip install -r requirements.txt` in an existing environment. This uses the default PyTorch package rather than selecting the CPU wheel explicitly.

Expected example output:

```text
Prediction shape: (2, 11, 2)
Re-encoded token shapes: [(2, 5, 16), (2, 2, 16)]
PASS: finite forward outputs and backward gradients on CPU.
```

The example composes initialization, one update, weight decoding, coordinate evaluation, and re-encoding. It uses randomly initialized parameters and synthetic inputs. It is a component wiring example, not a pretrained inference demo or the full paper rollout.

## Supported scope

| Item | Initial release |
| --- | --- |
| Weight grouping | Output-neuron / row grouping (`column_grouping=False`) |
| Weight codec | Linear-layer weight matrices; biases are not generated by the codec |
| Attention width | Divisible by 8, matching the attention wrappers' eight heads |
| Example inputs | Task embeddings `[batch, tokens, dim]` and coordinates `[batch, queries, 3]` |
| Tested update configuration | `use_hyper_crossattn=True`, `enable_each_layer_lr=True`, `slice_dl_din=False` |
| Validation environment | Python 3.12, PyTorch 2.7.1 CPU, einops 0.8.1 |

Other legacy options are not part of the validated scope. Column grouping raises an explicit `NotImplementedError` until its tensor layout has been reviewed. The component classes retain the supplementary-code interfaces, but this repository is not yet a drop-in replacement for the full supplementary project.

## Release notes

The core classes were selected from the supplementary source. Changes in this initial subset are limited to import cleanup, removal of commented debug statements, documentation, and explicit rejection of the unvalidated column-grouping path. The attention wrappers retain the supplied implementation. The example and tests are new additions for checking this subset.

Dataset-specific training modules, NeRF rendering utilities, third-party source, machine-specific environment exports, datasets, checkpoints, and generated outputs are intentionally excluded from this initial release.

Passing the component checks establishes that the documented example executes and differentiates; it does not establish benchmark accuracy or full experimental reproducibility.
